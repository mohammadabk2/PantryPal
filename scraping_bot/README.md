# Scraping Bot

This bot is designed to fetch and process price data from various supermarket chains. It downloads XML files containing price information, cleans the data by removing unwanted elements, and filters out non-food items. The processed data is then merged into a single JSON file for easy access and analysis.


## Installation

To install this project, you will need to have Python 3 installed. You can then install the required dependencies by running the following command:

```bash
pip install -r requirements.txt
```

## Usage

To run the bot, you can use the following command:

```bash
python3 getPriceData.py
```
